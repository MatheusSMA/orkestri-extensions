# Duck Mode

Two dark themes for Orkestri from the colours of **Duck Mode!**, the VS Code theme by MEvesalTR (Mohammad Erfan
Vesaltalab Ravari):

- original: https://marketplace.visualstudio.com/items?itemName=MEvesalTR.duck-mode-vscode
- its source: https://github.com/MEvesalTR/duck-mode

| Theme | Looks like |
| --- | --- |
| Duck in the Dream | near-black (`#110f17`) with purple (`#9b78ff`, buttons and selection) and yellow (`#ffbe41`, the glyphs of the canvas tools, warnings, ropes) |
| Duck in the Lake | slate (`#1d222d`) with gold (`#ffcc66` on tints, warnings and ropes) |

In Duck in the Lake the accent is a deeper gold (`#c08a28`) than the original's `#ffcc66`: Orkestri writes white on its
accent (primary buttons, the lit menu row), which would not read on the light yellow. The terminals' own colours are not
part of an Orkestri theme: Settings › Terminal › Aparência chooses them.

Licence: the original is MIT licensed (see LICENSE.md, its notice as published). This package holds none of its files,
only its colours as Orkestri's tokens; the icon is drawn for this package. The original says Duck in the Dream is a
customized version of the Aura theme and Duck in the Lake of Ayu.

Use: install it from the store, then choose a theme in the theme center (Configurações › Geral › Sistema › Aparência ›
Central de temas) or press "Usar tema" in the store.
