# Música

Spotify or YouTube Music inside Orkestri.

- **Adicionar › Música › Spotify / YouTube Music** opens the service's web player in a card. Sign in there once: the
  login is kept (the portals' shared login) and the card plays on while it is off screen or another workspace is shown.
- **The pill** in the canvas corner shows what plays (track and artist) with back, play/pause and next.
- **Terminals**: link a terminal to the card and its agent controls the music:
  `orkestri portal music "Spotify" play|pause|next|prev|now`.

Spotify's web player needs a browser able to play protected music (Widevine); if it does not play in Orkestri, use
YouTube Music. Nothing is downloaded or installed: the services' own web pages.
