# Lucid Volcano

Two dark themes for Orkestri with a pink-red accent, from the colours of **Lucid Volcano**, the VS Code theme by
Marcos Gabriel:

- original: https://marketplace.visualstudio.com/items?itemName=MarcosGabriel.lucid-volcano
- its source: https://github.com/Resmung0/Lucid-Volcano

| Theme | Looks like |
| --- | --- |
| Lava | greys (`#1f1f1f` around, `#292929` canvas) with the pink-red `#f20d63` |
| Magma | navy (`#181b28` around, `#1e2031` canvas) with the pink-red `#f20d63` |

Both keep the original's popup black, greys and purple (`#252234`, `#474c60`, `#891fff`, on the ropes between cards).
The terminals' own colours are not part of an Orkestri theme: Settings › Terminal › Aparência chooses them.

Licence: the original states no licence. This package holds none of its files (no theme file, image or logo; the icon
is drawn for this package), only its palette re-expressed as Orkestri's colour tokens, with credit to its author.

Use: install it from the store, then choose Lava or Magma in the theme center (Configurações › Geral › Sistema ›
Aparência › Central de temas) or press "Usar tema" in the store.
